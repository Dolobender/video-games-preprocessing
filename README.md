# Предобработка данных о продажах видеоигр (2000–2013)

Учебный проект Яндекс Практикума, спринт «Python. Предобработка данных».

## Задача
Подготовить данные о продажах видеоигр для статьи об игровой индустрии начала 2000-х: очистить данные, отобрать период 2000–2013, разбить игры на категории по оценкам и выделить ведущие платформы.

## Данные
Исторические данные о продажах игр из открытых источников: название, платформа, год выпуска, жанр, продажи по регионам (Северная Америка, Европа, Япония, другие страны), оценки критиков и пользователей, рейтинг ESRB. Датасет предоставлен Яндекс Практикумом и в репозиторий не включён.

## Что сделано
- названия столбцов приведены к snake_case, исправлены типы данных;
- пропуски в продажах заполнены с группировкой по платформе и году выпуска;
- устранены неявные дубликаты (разный регистр жанров и платформ) и удалён 241 явный дубликат (2,2% данных);
- отобрано 12 781 игра за 2000–2013 годы;
- добавлены категории по оценкам пользователей и критиков (высокая / средняя / низкая);
- определён топ-7 платформ по числу игр: PS2, DS, Wii, PSP, X360, PS3, GBA.
